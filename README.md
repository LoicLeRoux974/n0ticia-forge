# N0ticia Forge

Voici le prompt system en pièce jointe ainsi que le vademecum en pdf.
Je voudrais un outils qui génère automatiquement une fiche Noticia pour des formations.
La personne viendrais avec un document type pdf et demanderai de générer une fiche Noticia. Le prompt système et le vademecum sont les bases réglementaire de la fiche Noticia.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://n0ticia-forge.lovable.app
